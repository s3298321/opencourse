# Paper & Ink

An example OpenCourse theme that uses every part of the format: a light
appearance, a picture behind the window, a woven texture on the chapter list,
its own grain texture, fonts named from macOS (Charter, Avenir Next, Menlo) and
one bundled font - Ledger Dots, a dot-matrix face used for the wordmark.

Zip this folder and import it from Settings → Appearance. See
`theme-format.md` for what each field does.

The pictures and Ledger Dots were drawn by code for this example. They are
free to use, change and share, in your own themes or anywhere else.
